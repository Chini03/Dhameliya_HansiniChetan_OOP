What the Counter class does

  • Creates a counter interface inside a container (selector)
  • Displays the current count
  • Adds Increment, Decrement, and Reset buttons
  • Updates the count when buttons are clicked
  • Disables Decrement and Reset when the count is 0
  • Keeps the UI updated with the current value

What problem it solves

It encapsulates all the logic for a counter in one class, so you don’t have to repeatedly write DOM creation, event listeners, and state logic every time you want a counter.

Because of this, other classes (like StepCounter) can extend it and reuse the same functionality while only modifying the parts they need (e.g., changing how increment/decrement works).

Example HTML container markup

Create a container element in your HTML where the counter will be rendered. The class will dynamically insert the display and buttons inside this container.


                    <div id="counter-container1"></div>
                    <div id="counter-container2"></div>
                    <div id="counter-container3"></div>
                    <div id="counter-container4"></div>
  • Each container must have a unique selector (usually an id).
  • The Counter class uses document.querySelector() to locate the container.
  • The counter display and buttons are automatically generated and appended inside the container.

Example instantiation code

Import the counter classes and create new instances.


                    const counter1 = new Counter("#counter-container1", 10);
                    const counter2 = new Counter("#counter-container2");
                    const counter3 = new Counter("#counter-container3");
                    const counter4 = new StepCounter("#counter-container4", 10, 5);
  • Each new Counter() creates a separate counter widget.
  • The counter automatically mounts itself into the container specified by the selector.
  • StepCounter extends Counter and allows custom step values.

Explanation of parameters

Counter Class


                new Counter(selector, initialValue)
  • selector - CSS selector of the container where the counter will appear
  • initialValue - Starting value of the counter (default is 0)

Step Counter Class


                new StepCounter(selector, initialValue, step)
  • selector - CSS selector of the container where the counter will appear
  • initialValue - Starting value of the counter (default is 0)
  • step - Amount added or subtracted when incrementing or decrementing
